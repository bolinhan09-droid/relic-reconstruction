# 遗迹重构 · 标签节点创作台

在服装照片上圈选、绘制并讨论战损方案，再整理制作位置和材料试样。Windows 桌面窗口，本机保存；支持独立配置本地图像模型、本地对话模型和在线 API。

这是课程项目的第一版可运行原型，预发布标记为 `v0.8.1-prototype`。当前优先用于小组试用、讨论和继续开发。

**组员从这里开始：** [安装与首次试用](docs/TEAM_SETUP.md) · [版本说明](RELEASE_NOTES.md) · [Windows 预发布下载](https://github.com/bolinhan09-droid/relic-reconstruction/releases/tag/v0.8.1-prototype)。仓库为私有，需要先接受协作邀请，并登录获得授权的 GitHub 账号。

## 标签节点工作流 v0.8.1

上传真实服装正面，点击开始，图片缩入第一个标签。底部按输入、设定、创作、AI、结构、制作提供 20 个节点，原有 19 个保留，新增 AI 识别与检索。点击添加或拖到主线；参考与设定插在上方，AI 协作可以插在下方，角色检索卡插在上方。选中节点按空格进入其工作区，按 Esc 返回。

主线可以重排、反复精修、先映射再设计。撤下节点进入方案架，已有输出保留。修改上游会标出下游旧版本，不自动重绘。保存与恢复使用本机工作区的 `node-studio/workflows`；原有项目继续保存在 `projects`，旧完整工作台可从 `/legacy` 访问。

节点可以直接拖回底部撤下，再从方案架拖入主线任意连接处加塞。松手前显示插入位置，拖回不会删除该节点的输出与历史。原按钮与键盘操作继续可用。

“AI 识别与检索”先使用你配置的视觉助手读取服装缩略图，提出虚构角色候选；确认角色后，再检索公开背景资料并选择场景。远程识别首次需要同意发送缩略图，已授权项目可在插入节点后识别一次，不会自动重试。没有视觉接口时明确显示未就绪。检索失败不伪造结果，已有资料会标明缓存与来源；只有明确采用的场景才影响后续任务。

精修画布新增跟随放大镜：按住 M 临时查看，也能固定开启并切换倍率。镜片偏离笔尖，采样当前绘制后的真实画布，不进入保存图片。可选开启摄像头靠近感知，校准平时坐姿后，靠近触发、退后收起；它依据相对脸框变化，不测量真实距离或视线。默认关闭，视频仅在本机内存处理。依赖、使用方式与边界见 `docs/PROXIMITY.md`；缺少可选感知环境时仍可直接使用 M 键放大镜。

- 快速生成、AI 选区和三角融合准备生成任务；模型、API 和显式生图都在图像生成节点。连接或保存不会发起生图。候选返回后需要明确采用。
- 精致修改接入原有详细笔刷、独立痕迹、保护区、表面贴合和背景开关。服装分割当前为真实矩形选区与裁切，展平与映射使用真实平铺照片和用户确认的对应点。
- 三角融合是多参考偏好控制，模型执行时发送真实候选，不声称照片之间存在数学精确的语义插值。
- 想法整理、修改建议、审阅和协作执行先提供注明来源的本地规则辅助。它们不是已经验证的视觉大模型审美判断。
- 手势节点有鼠标/触控草稿，战斗节点有可操作的二维事件原型；摄像头手势识别、完整三维战斗和任意服装自动配准尚未接通。另有可选的人脸框靠近感知，仅用于触发放大镜。
- 辅助模板支持用户确认尺寸和位置后的简单 SVG/DXF 镂空窗口初稿，不是自动提取任意血迹、更不是缝制服装裁片。

开发结构见 `docs/ARCHITECTURE.md`，交互参考与取舍见 `docs/INTERACTION_REFERENCES.md`。节点目录集中在 `node_studio/catalog.py`，内部工作区、连接规则和数据保存分别维护，后续视觉可以独立替换。

## 直接使用 Windows 版

1. 将整个发布包解压到可写目录，例如 `D:\RelicReconstruction`。不要只取出 EXE。
2. 双击 `RelicReconstruction.exe`。无需 Python、Node.js、ComfyUI 或 LoRA 训练环境。
3. 系统需有 Microsoft Edge WebView2 Runtime；Windows 缺少时从 [微软官方页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装。
4. 照片、方案、制作记录、窗口草稿保存在软件旁的 `workspace`，可以整目录备份。更新时保留此目录。

默认使用本机 `127.0.0.1:17870`。没有公网服务；关闭桌面窗口会关闭本次软件启动的后台进程。不会停止另行运行的模型服务。端口冲突会提示，不会停止别的软件或自动换到空白草稿。

## 从源码启动

Windows 10/11、Python 3.10–3.12 x64。双击 `install-desktop.cmd` 安装项目隔离环境，再双击 `start-desktop.cmd`。安装脚本会依次查找 3.12、3.11、3.10，避免误用尚未验证的更新 Python 版本。

也可手动：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python.exe desktop.py
```

使用其他数据盘：`python desktop.py --data-dir D:\RelicWorkspace`。目录必须是绝对路径。源码浏览器版仍可用 `python -m uvicorn app:app --host 127.0.0.1 --port 7870`，默认使用源码 `data`；与桌面工作区独立。

## 不同模型怎样使用

|方式|能做什么|设置位置|
|---|---|---|
|不装模型|本地笔刷、保护区域、方案保存、制作位置导出、手动导入生成图|直接开始|
|本地对话服务|助手讨论和笔刷参数建议；不等于图片生成|AI 助手设置 → 本机模型|
|本地图像编辑服务|接收原图、区域示意和指令，返回编辑图片|图像服务 → 本机图像编辑|
|在线 API|按所选服务提供对话或图像编辑|对应的助手/图像服务设置|
|既有 ComfyUI + SD1.5|保留旧版分区域实验，不等于新画笔效果已验证|本机模型 → 原有实验服务|

本地对话接受 OpenAI 兼容 `POST /v1/chat/completions`（例如已启动并加载聊天模型的 Ollama/LM Studio）。本地图像接受 `GET /v1/models` 与 multipart `POST /v1/images/edits`，要求返回 `data[].b64_json`。**聊天模型和兼容聊天地址不自动具备生图能力。** 本机地址仅支持 loopback；可不填密钥。`/models` 能读取只证明连接可用，不证明图像编辑质量。

本版本不捆绑模型权重，不自动下载或启动第三方模型程序。可将授权的模型包放在 `workspace/models`，或在“本机模型”选择目录；目录扫描不会执行包内代码。当前登记面板识别 safetensors；GGUF 模型由其独立推理服务管理，填服务地址即可，不能把 GGUF 放进去就称已接通。

模型包样例见 [models/README.md](models/README.md)。轻量本地编辑候选为 FLUX.2 klein 4B + stable-diffusion.cpp；本项目未完成其真实推理/画质验证，见 [模型接入说明](LOCAL_MODELS.md)。

API 密钥只在当前后台进程内保存，软件重启后重新填写；不会把云端密钥自动交给本机服务。配置本机模型不产生云端请求。点击在线生成或联网资料查询才会按功能联网；授权助手查看照片后才会发送照片。

## 创作流程

准备素材与场景 → 圈选/笔刷/AI 协作 → 精修对照与采用 → 制作辅助。图像效果是视觉方案，材料渗色、变硬、清洗和破坏程度必须以实物小样验证。

血迹分为“定点飞溅”和“浸染涂抹”。按住起点朝目标方向拖动，松手生成一次飞溅；选中这次痕迹后，可调整力度、血量、主滴尺度与散布，点击“更新所选血迹”。方向与力度也可预设后直接点按。浸染支持连续涂抹、叠刷加深和数位笔压力；普通鼠标使用稳定压力。新血迹会参考底图明暗调色，这是程序化视觉预览，不是经过校准的材料模拟。

### 褶皱贴合与背景显示（v0.7）

画布上方“衣服表面 → 分析衣服表面”在本机执行一次前景分割与相对深度估计。分析完成后，“褶皱贴合”让血迹、磨损、焦痕等透明笔触参考局部凹凸改变形状，强度可调、可关闭。场在原始照片上缓存，每笔不重新调用模型。绘制预览、精修引导/权限图、平铺映射使用相同的表面几何；保护区域在变形后再次裁剪。未开启的新旧项目保持原笔刷算法。

“隐藏背景 / 显示背景”只切换画布显示，原始照片不删除。前景包含整个人物、头发、衣服及可能的手持道具，可以下载透明主体；它不是衣服分件、布料或材质识别。背景按钮不触发新生成版本。已分析前景可独立用于对应算法，排除画面杂物；照片改变后不能继续套用旧场。

本轮真实运行U2Netp前景模型和Depth Anything V2 Small相对深度模型，默认权重约104MB；不需要训练LoRA。Cos实测保留头、手、帽子和披风主体，尖细边缘偏软、椅子仍有少量残留。单张图的明暗、反光和颜色不能可靠区分真实高度；此功能是可关闭的2.5D视觉近似，不是精确褶高、物理血液/布料吸收、完整3D或遮挡恢复。

公开软件包不含权重。需要独立Python模型环境安装 `requirements-surface.txt`，运行 `tools/download_surface_models.py` 获取固定版本和哈希；首次分析会实际检验运行条件，不将找到权重等同于已验证画质。在工作区 `runtime/surface-runtime.json` 设置 `pythonExecutable`、`modelDir`、`scriptPath` 指向 `tools/analyze_garment_surface.py`；可执行路径不从网页提交。基础笔刷与已有缓存场的实时绘制不依赖联网服务。

### 用户平铺照与自动建议对应（v0.6）

在“衣片映射”上传同一件衣服、同一可见面的真实平铺照，点击“自动建议对应点”。背景或衣片层次混淆时，分别点击“框选源衣片”和“框选目标衣片”，在左右图各圈出同一个部件后重新建议。建议点可直接拖动，也可改下方数值。核对同号点后，点击“确认对应点并生成映射”，再导出透明痕迹层与对照图。

基础算法按同一可见衣片的轮廓纵向分段、横截面比例建立近似对应，不需要模型和API。复杂背景、多个前景或明显分叉会请求框选，避免把人、内搭和披风连成同一块。它不是布料物理展开，不恢复褶皱下的隐藏面积。用户矩形只是范围近似，不等于已经识别出真实衣服边界。

默认“整体位置优先”采用可用的轮廓比例初稿。可在折叠设置中切换“AI语义匹配实验”：可选DINOv2-S/14在本机提取视觉特征，以互选、特征差距、上下左右位置先验和网格不翻折筛选可编辑候选。使用官方预训练模型，无需训练LoRA。真实公开同衣配对中，肩带和部分侧边可对应，纯黑主体仍有高分错配，所以建议必须人工核对；余弦分数不代表准确率。候选不合格时保留轮廓近似或请求重新选择，不自动补造对应点。

完整Windows包的轮廓近似无需额外Python。启用DINOv2需在独立Python环境安装 `requirements-correspondence.txt`，运行 `tools/download_correspondence_model.py` 下载固定版本约88MB权重，再在工作区 `runtime/correspondence-runtime.json` 设置 `pythonExecutable`、`modelDir`、`scriptPath`（本项目的 `tools/dino_garment_correspondence.py`）。配置文件只在本机编辑；网页不能指定任意可执行文件。公开发布包不含权重和课程样本，下载工具只读取公开模型，不发送照片。

平台保存的独立笔刷层可以直接迁移。已有精修图使用记录范围内的图像补丁；外部合成照片没有独立痕迹时，无法无损分离血迹，只能迁移可见纹理。输出记录会保留建议来源、用户是否修改点位、覆盖范围与未知范围。上述范围比例不是实物制作精度。

### 详细笔刷与衣片映射实验（v0.5）

保留原工作台布局。四类主工具内增加16种实际程序化子类型：血迹飞溅／浸染／流淌／接触擦抹，刀口／撕裂毛边／破洞，擦伤／磨白／泥点／泥污／积尘／水渍，焦黑／烟熏／沿边焦化。血迹另有干燥、湿润、陈旧外观。固定种子与形状记录支持保存重放，不是血液或布料物理仿真。

画布标题区的“衣片映射”打开新功能。先保存方案，再上传真实平铺图；在源照片与目标照片上成对标记同一部位，至少3对不共线，建议沿同一衣片轮廓和内部接缝补点。使用独立图层与分片仿射迁移，支持导出透明痕迹、原图形变、覆盖、未知区域、网格和记录包。该功能需要人工确认对应点，尚未实现任意复杂Cos服自动稠密对应，也不代表实测布料展开精度。

如果当前图是已经采用的精修结果，软件会在当前照片与历史任务结果一致时恢复对应笔触快照；无法验证时只搬移可见照片纹理，不声称自动分离血迹。源图、保护区、精修图和版本变化会使缓存失效。全局交叉／翻折网格拒绝生成。

本机MGT预训练平铺模型为可选研究扩展。在RTX4060 Laptop 8GB上完成真实推理，但本项目复杂蓝黑披风案例的结构保真和痕迹位置保持均未通过；界面显示实验警告。模型生成图可作设计候选，不能填写未经校准的实物尺寸。遮挡处外观为推测，隐藏痕迹续接尚未验证。

研究扩展、权重及个人实验保存在本项目本机目录，未混入MIT源码发布包。MGT使用SSPL许可。可在工作区 `runtime/flatlay-runtime.json` 配置本机已安装的 `pythonExecutable`、`modelDir`、`scriptPath`；配置仅本地编辑，不从网页提交任意可执行路径。分享给其他电脑时，需分别安装和核对该研究扩展，不能只复制模型权重就宣称已经接通。

本次未训练新模型：现有材料没有同一件Cos服的真实穿着—平铺配对和遮挡对应标注，无法据此验证新模型的保真。预训练尝试、几何映射和实物制造验证分别记录，不能用程序化变形或生成图片充当新训练模型结果。

旧血迹保留原样。若想换成新笔刷，可回到这一轮绘制，点击“清除这轮血迹，保留其他痕迹”，再重新绘制；也可选一笔“用新笔刷重做所选血迹”。生成图需要重新精修，不会自动改善旧成品。

“我的方案”打开工作区中的历史保存；当前草稿保存在独立窗口的持久存储。初次从旧浏览器版迁移不会读取浏览器私有草稿：先在旧版保存，再复制 `uploads/projects/jobs` 到新工作区后从“我的方案”打开，或保留原浏览器版本继续访问。

## 构建与分发

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe tools/build_desktop.py --output release
```

生成 Windows onedir 完整目录、免安装 ZIP 和可上传 GitHub 的干净源码 ZIP。构建脚本以白名单收集源文件，不包含个人照片、工程、密钥、日志和模型权重。发布封面使用自绘几何海底图；本机个人主题图片不进入源码/发布包。

仓库存放干净源码，Windows ZIP 作为预发布附件。不要上传日常使用后的 `workspace`、`data`、个人照片、API 密钥或模型权重；当前 `.gitignore` 已排除常见工作区和权重文件。更新时保留自己的工作区，每位组员独立配置需要使用的模型接口。

本版已验证 Windows；未生成 macOS/Linux 安装包。依赖/第三方素材范围见 [LICENSE](LICENSE) 与 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
