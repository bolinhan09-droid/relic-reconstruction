把创作拼起来

  1. 横向接，继续创作。

    从底部拖一个节点到两个步骤的连接处，看到“插入此处”后松开即可加塞。也可以点击添加，用左右按钮或 Alt + 方向键调整。

  2. 侧边插，给这一刻加个助手。

    参考和设定放上方，AI 协作放下方。先选中宿主节点，再添加或拖入。

  3. 双击进入，Esc 回来。

    双击标签输出或按空格，直接进入工作台。接入 AI 不会自动跳页或调用接口。

  4. 分出路线，再收集方案。

    选择任意步骤后点“从这里分支”，原后续保留为方案 A；方案 B 独立创作。合拢节点收集各路线的输出，后面可接融合创作。Ctrl + 滚轮缩放，拖动空白平移。

  5. 拖回底部，保留这次尝试。

    将节点拖回节点库或方案架即可撤下；下方方案架里的卡片可以再拖回主线任意连接处。也可使用“撤下”按钮或 Delete。修改上游后，下游旧结果仍可查看。

实验节点会说明当前能力。图像效果是设计预览，实物材料仍需要小样验证。
