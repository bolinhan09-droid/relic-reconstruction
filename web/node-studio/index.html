帮助与教学

用示例走通精修、保存和输出，不需要配置模型

  1. 双击进入，Esc 返回

    连接节点不会自动生图或打开工作台

  2. 连起来，或独立放置

    拖到标签之间连接，拖到画布空白处独立放置，输出会保留。也可用“放到画布”和“连接到…”按钮

  3. 多张图片，多条路线

    用上方“＋ 服装”“＋ 参考图”添加图片，每张都能延伸工作流。拖动路线标题旁的手柄可整体移动

  4. 参考在上，AI 在下

    拖入节点侧边的插槽。选中步骤点“分支”可探索多个方案

  5. 收起与找回

    拖回底部或点“收起”，节点进入方案架；可再拖回画布或连接处。Ctrl + 滚轮缩放，拖动空白平移
