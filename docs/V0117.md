# v0.11.7 · Windows 公开体验版

## 下载与开始

从 [本版 Release](https://github.com/bolinhan09-droid/relic-reconstruction/releases/tag/v0.11.7) 下载 `RelicReconstruction-Windows-x64.zip`，完整解压后双击 `RelicReconstruction.exe`。不需要 Python 或大模型。包内 `开始使用.txt` 提供简短说明；系统需 Microsoft Edge WebView2 Runtime。

首页恢复 v0.10 的比例：左侧介绍和开始入口、右侧适中大小的磨损标签、下方横排历史作品。保留标准/自由流程、作品删除和示例教学；内部继续使用 v0.11 的固定工作台、分支、节点输出、制作路线与版本切换。

## API 怎么填

首页与“帮助”中的“API 怎么填”提供三步引导，可随时关闭与重新查看。左上角“AI 设置”是统一入口；工作台顶部也可以进入。

| 目的 | 配置位置 | 接入能力 |
| --- | --- | --- |
| 讨论想法、修改建议、协作执行 | 协作助手 | 对话模型；识别或审阅图片须支持视觉输入 |
| 生成、精修图片 | 图像服务 | 图像生成/编辑模型 |

同类节点共用设置，不必逐个填。手动输入的密钥只保存在本次后台进程内存，重启后需要重新填写；也可使用已有环境变量配置。密钥不会写入作品和导出文件。只有执行云服务时才把所需内容发送给对应服务商；安装、打开软件、连接节点不发起生图。

### 在哪里开通千问

1. 登录 [阿里云百炼控制台](https://bailian.console.aliyun.com/)，按提示开通服务。
2. 在 API Key 页面创建密钥；在业务空间管理查看工作空间 ID。地域、密钥与接入地址要对应。
3. 返回软件的“AI 设置 → 图像服务”，选择千问，填写 API Key 和工作空间 ID，在高级设置核对地域。本版图像连接使用工作空间地址，默认模型由软件提供。
4. 需要千问视觉助手时，在“协作助手”选择兼容服务，按百炼官方文档填写兼容地址和支持视觉的模型。图像模型名称不能填进对话助手字段。

官方 [首次调用指南](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)、[API Key 管理说明](https://help.aliyun.com/zh/model-studio/get-api-key/)、[图像生成与编辑接口](https://help.aliyun.com/en/model-studio/qwen-image-generation-and-editing-api-reference)、[模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)。API 按服务商规则计费，免费额度以账户控制台显示为准。本版不附赠共享云额度。

## 无需 API 的体验

“跟着示例做一遍”使用软件内的示意服装，练习进入精修、绘制、保存与传递输出。已有作品不受影响。基础绘制、分支、项目保存与几何校正均可本机使用；需要额外模型的功能会显示未就绪，模型链接见 [LOCAL_MODELS](../LOCAL_MODELS.md)。

## 公开范围与使用边界

发布包不包含私人照片、个人方案、工作区、密钥、登录态或大型模型权重。只分发界面资源、示意服装和已声明许可的小型手势资源。源码包与 Windows 程序来自同一份整理后的发布快照。

真实服装的平铺映射仍需用户提供照片并核对位置和尺寸；AI 展平是参考图，不是可靠的缝制裁片。模板不能替代材料小样。当前是 Windows x64 公开体验版，尚未提供 macOS/Linux 桌面包。

更新前关闭旧程序，保留本机工作区；固定目录用户使用既有更新工具，操作见 [更新说明](V011.md)。反馈请提供版本、操作步骤与错误信息，避免提交私人素材或密钥。
