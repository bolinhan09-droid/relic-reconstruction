# v0.11 自由创作台

## v0.11.4 新手练习与固定工作台

首页和工作区帮助新增可跳过、可恢复的示例练习，通过真实绘制、保存和下游读取学习节点操作，无需 API。入口、创作画布与节点参数改为窗口内分区滚动，保留当前视觉风格。使用方法见 [新手练习说明](V0114.md)。

## v0.11.3 节点联动与全局 AI 设置

“想法整理”可把整理好的文字保存为节点输出；图像生成同时读取当前路线的服装图片和文字要求，展示来源，保留用户补充要求。独立路线和兄弟分支不会混用文字。上游改变后，下游已有成品保留并标记待更新；不会自动再次调用模型。

首页、创作画布和工作区提供同一个“AI 设置”入口。协作助手用于构思、搜索、建议、审阅和执行；图像服务用于实际出图。每类配置一次，节点共用连接。图像节点默认跟随全局，必要时可以单独指定已配置的服务；模型名、地址和质量收进高级设置。原有单独模型配置可选择改为跟随全局。API Key 不进入作品或导出文件，目前仅在本次程序运行中使用。

Esc 关闭当前设置面板，或从节点工作区返回画布；输入框中也可使用。未完成的绘制手势优先取消，已修改的笔触仍按保存协议处理。真正关闭、刷新窗口时的未保存提醒保留。

应用仍为本机 Windows 桌面软件，编辑器使用网页技术，与本机浏览器入口共用核心功能。此更新没有新增公网托管、账号同步或多人实时协作，也没有迁移个人照片。

## v0.11.1 修复

修复同一用户窗口保留旧 HTTP 缓存、升级后仍整页显示 v0.9 的问题。入口会绕开旧缓存并校验实际界面，脚本、样式及嵌入式工作区使用新的版本资源路径；无需删除窗口档案或本机作品。

AI 协作节点、角色识别与检索、精修助手这三个设置入口统一简化：选择 DeepSeek 官方服务后只需填写 API Key，软件补齐官方地址和默认模型 `deepseek-flash`。需要指定其他模型时展开“高级设置”。第三方中转和本机模型仍按各自服务配置。

连接流程与页面行为使用模拟接口和本机浏览器验证；没有将真实付费 API 调用作为本次验证结果。

## 开始创作

上传服装照片后选择“标准工作流”，常用步骤会直接摆在画布上。熟悉操作后可以选择“自由工作流”，从输入节点开始搭建。

默认步骤为服装输入、快速生成、图像生成、精致修改、制作指导。快速生成准备要求，图像生成负责模型配置与实际调用。开始工作、连接节点和保存方案都不会自动生图。没有配置模型，也可以直接进入精致修改。

双击节点输出进入工作区，Esc 返回。说明文字在“操作说明”中展开查看。

## 自由摆放与多个起点

- 把普通节点拖到空白处，节点会脱离原路线，保留已有输出
- 拖回连接处可以重新接入；也可使用节点操作中的连接选项
- 新增服装或图片参考会产生独立起点，每条路线可以继续添加步骤、分支与合拢
- 图片参考支持多张图，先选择其中一张作为当前输入；需要同时探索时使用多个参考节点
- 画布位置、输出、路线和附件一起保存，重新打开后恢复

改变连接会将依赖旧输入的后续结果标为待更新，不删除成品，也不自动重绘。分支和合拢作为完整结构保留，不能单独拆散。参考路线可以探索图像；制作、实物映射和模板需要该路线中的真实服装依据，不会借用别条路线的服装。

## 固定入口与更新

程序文件和个人资料分开放置：

```text
安装目录/
  当前版本/             正在使用的程序
  上一版本/             更新器保留的上一个程序
  程序更新/RelicUpdater.exe
  桌面版工作区/         照片、工程、模型路径配置与窗口草稿
```

日常打开固定入口，无需寻找版本号。以后取得新版 Windows ZIP 和同一发布页的 `SHA256.json`，放在一起，关闭软件后打开“更新遗迹重构”，选择 ZIP 即可。更新器核对包校验和逐文件清单后才替换“当前版本”，替换失败会尝试恢复原程序。它不会搬动或覆盖工作区、照片、模型。

从源码使用更新器：

```powershell
python tools/update_desktop.py --install-root D:\RelicReconstruction --data-dir D:\RelicWorkspace --package D:\Downloads\RelicReconstruction-Windows-x64.zip
```

也可把发行包中的 `RelicUpdater.exe` 单独放到安装目录的 `程序更新` 文件夹，再传入相同的 `--install-root` 与 `--data-dir` 参数。更新工具应位于“当前版本”外，避免覆盖正在运行的更新器。源码包不能作为桌面更新包。

此版提供本地更新包安装，不会静默联网下载更新。首次升级前保留自己的工作区备份。

固定安装后，直接打开“当前版本”里面的 EXE 也使用外部工作区。普通 ZIP 解压运行仍默认使用 EXE 旁的 `workspace`。如需回到更新前的程序，可以关闭软件后给更新器传入 `--rollback`；回退不会倒退作品内容。

## 删除旧作品

“我的创作”和首页最近作品卡片都提供删除入口。确认框显示作品名称和预计释放空间，确认后删除作品记录、历史版本及未被其他作品使用的关联素材。

其他作品及其历史仍引用的图片会保留，独立的旧版项目也会保留。不能确认归属的素材不自动清理。删除后显示实际释放空间；运行中的处理任务结束后才能删除。此操作不会删除原照片所在的电脑文件夹、模型或软件配置，已删除的本机作品无法从方案架恢复。

## 启动与排查

默认端口为 `17890`。重复打开同一工作区会定位已有窗口；启动检查同时核对程序版本、工作区和本次实例，避免连到旧后台。

若无法启动，提示窗口会指出日志位置。日志位于工作区 `runtime`，可保留日志排查，不需要删掉工作区重试。其他程序占用端口时会明确提示，不会擅自结束它。不要同时使用旧版入口编辑同一个工作区。

## 兼容性

原有主线、分支、合拢和方案架保持兼容。新增独立路线保存在 `routes` 中。旧版软件不认识这部分结构，升级后的工程应继续使用 v0.11 或更高版本。

算法、模型和实物制作的能力边界未改变，见 [模型指南](../LOCAL_MODELS.md) 和 [v0.10 功能说明](V010.md)。
