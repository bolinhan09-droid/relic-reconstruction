# v0.11.6 创作体验更新

继续使用原来的“打开遗迹重构.cmd”。程序仍安装在“当前版本”，照片、作品、API 设置和模型保存在原工作区。

## 从方案进入制作

打开“制作指导”，点击“把方案做出来”，当前路线后自动接好：

**平铺照片 → 核对映射 → 模板制作**

重复点击会打开已经接好的路线。平铺照片单独保存为目标，不覆盖穿着图、已有笔触或原始底图；进入核对映射时自动读取，不用再次上传。映射需要核对实际对应位置，制作模板仍需实测尺寸，软件不会从照片编造毫米尺寸。

模板节点输入有效宽高后即可生成，不再重复勾选确认框。换一张映射图会清除旧尺度，避免沿用另一张衣片的尺寸。生成的制作包在当前工作台显示，并保留 ZIP、说明书及定位文件下载。

## 血迹飞溅

- “局部细溅 / 大范围飞溅”快速选择，范围和力度分别可调
- 按下起点并拖动定向蓄力；覆盖范围决定大面积分布，血量决定疏密
- 主斑、大小液滴与拖尾使用不同分布，减少重复规则形状
- 调整选中血迹后直接更新，可撤销；浸染、自定义颜色、保护区与材质融合继续可用
- 旧作品保留原来的随机种子与图形，不因更新重新生成形状

这是可编辑的程序化效果预览，不等同于真实流体仿真。布面融合依赖可用的表面辅助信息，照片级精修仍由图像模型完成。

## 结果与工作台

图像生成、服装分割、展平处理成功后，直接替换主画布，不再点击“采用”。生图历史通过画布旁的“版本”入口切换，失败时保留当前画面。分割与展平可切换选区和当前结果。

工作台保持固定高度。长设置与说明通过上一页 / 下一页查看；主操作固定在底栏。画布缩放、拖动、绘制，以及输入框内部的编辑行为保留。工作区分页不占用滑杆原有的键盘操作。

主画布按可用空间完整适配，不修改图像坐标和笔触数据。保留现有配色和标签风格，没有更换 UI 框架。

## AI 连续协作

协作节点保存当前路线上的短对话，可继续说“再淡一点”“领口保持干净”。“固定要求”保留需要一直遵循的限制。协作执行点击“一起修改”后直接执行允许的本地操作并更新宿主画布，可从历史入口切回；切回不会删除后续节点。

连接、打开节点与切换版本不会发起图像生成。点击生成或一起修改才提交对应请求；失败不自动重试扣费。整体审阅与建议仍依赖已配置服务的真实能力，未配置模型时不会冒充 AI 分析。

## 模块边界

`core/making-route.js` 负责制作路线插入；`workspaces/flatlay-photo.js` 负责真实目标照片与源笔触并行传递；`workspaces/paged-workbench.js` 负责固定面板分页和画布适配；`workspaces/legacy-pages.js` 仅整理嵌入式精修和映射的界面，不改变绘制算法。

生图采用与历史逻辑在 `core/image-results.js`、`core/job-tracker.js`；AI 对话范围和历史在 `node_studio/assistant_conversation.py`；血迹几何仍在 `web/blood-engine.js`，保存与导出校验在 `brush_workflow.py`。

## 验证范围

使用合成服装图片完成节点连接、连续对话、自动显示、版本回切、笔触调整/撤销/重开和制作包真实下载。布局检查覆盖 23 类工作台及两种桌面尺寸。云服务部分使用模拟模型响应，不消耗真实 API 余额；外部模型最终图像质量需以实际账户生成为准。
