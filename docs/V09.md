# 遗迹重构 v0.9 · 分支创作台

## 从同一个起点探索

上传服装后，选择一个步骤，点击“从这里分支”。原来的后续步骤全部进入方案 A；空白方案 B 继承分叉点之前的衣服。点某条路线的“继续这条路线”，再从底部添加节点。每条路线可以命名，也可在路线内部继续分支。

修改方案 B 不会改写方案 A。上游变动后，受影响的旧输出会标记为基于旧版本，图片仍保留，用户决定何时重新生成。

## 合拢与融合

分支时自动建立匹配的合拢节点。双击合拢，查看各路线最后采用的图片，勾选本轮候选并保存。尚未采用的生成候选不会自动进入合拢。

在合拢后加入“融合创作”：两个方案用滑杆，三个方案用三角控制。若有更多方案，明确选择两至三个参与本轮；其余仍保存在原路线。选择衣服结构基准和融合范围，准备任务后，接入图像生成节点并主动点击生成。

合拢负责收集；融合节点负责表达偏好；图像生成节点负责实际调用模型。这三个操作分别保存，方便比较和回退。

## 总览与工作台

- 单击选择，双击标签输出直接进入内部工作台；Space 同样进入，Esc 返回。
- 接上 AI 节点不会突然跳页；图像生成仍需要主动点击执行。
- Ctrl + 滚轮缩放；Shift + 滚轮横移；拖动画布空白或按住鼠标中键平移。
- 右上角 − / ＋ 调整比例，点击百分比回到 100%，四角图标适应全部路线。
- 普通节点可拖到路线内的前后位置，或拖回底部方案架。方案架保存输出与历史。
- 分支起点与配对合拢不能单独拆走，避免失去路线的归属。

## 视觉与信息层级

入口：大幅上传标签、创作起点、最近的本机记录。

总览：横向标签作为主要操作对象，分支按独立横行展开；小型预览从随机磨漆区域露出。附件保持在标签侧槽。底部节点库承担添加与暂存，不与画布争夺主要空间。

工作台：统一浅色纸面、火漆红操作和灰蓝辅助色。以当前图片或设计控制为主，参数与服务设置分组，已有输出折叠显示。精修、分件与映射直接进入实际编辑器。

## 本版范围

本版新增完整的分支数据结构、合拢候选和缩放画布，保留 22 个节点入口。六个创作节点全部保留。原有笔刷、真实平铺图对应点映射、手动分件、制作模板和模型接口沿用已有实现。

融合比例是对图像模型的设计偏好控制，不是像素级的线性融合。自动服装展平、完整三维战斗、摄像头手势识别等尚未完成的能力仍在界面中明确标记。可用本地功能无需联网；使用在线生成和检索需配置相应服务。

## 数据与模块

旧线性项目仍可读取。新增 `branches` 保存每条路线的起点、名称与步骤，主线 `order` 保留匹配的分支 / 合拢节点。坐标仅用于展示，不参与数据依赖。

- `core/graph.js`：路线、依赖、候选收集和结构检查。
- `core/model.js`：添加、移动、撤下和提交输出的纯操作。
- `components/graph-canvas.js`：结构布局、连接线、拖放和缩放。
- `workspaces/`：各节点内部操作与输出。
- `node_studio/graph.py`：后端校验及路线继承，与前端使用同一语义。
- `styles/v09-*.css`：视觉、工作区和布局分别维护。
- `assets/v09/`：本地生成的纸面和磨漆素材。

本地版本更新不上传个人照片、历史方案或 API 配置。对外分发使用 Windows ZIP；源码包用于安装开发环境或后续协作。
