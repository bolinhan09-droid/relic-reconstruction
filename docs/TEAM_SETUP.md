# 组员安装与首次试用

这是《遗迹重构》的第一版课程原型。它在自己的 Windows 电脑上运行，不需要让项目作者的电脑保持开机。当前仓库为私有，需先接受仓库协作邀请，再使用获得权限的 GitHub 账号访问。

## 推荐：直接打开 Windows 版

1. 打开 [v0.8.1-prototype 预发布](https://github.com/bolinhan09-droid/relic-reconstruction/releases/tag/v0.8.1-prototype)。
2. 在 Assets 中下载 `RelicReconstruction-Windows-x64.zip`，不要把 GitHub 自动生成的 `Source code` ZIP 当成桌面程序。
3. 将整个 ZIP 解压到自己的可写文件夹，例如 `D:\RelicReconstruction`。保留 EXE 旁边的所有文件和 `_internal` 文件夹。
4. 双击 `RelicReconstruction.exe`。不需要另装 Python、Node.js、ComfyUI 或训练 LoRA。
5. 如果提示缺少 WebView2，安装 [微软 WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)，再打开软件。

下载的程序未购买代码签名证书。若系统阻止运行，请先核对下载来源是本仓库的 Release；不要关闭系统防护。Windows 10/11 x64 为当前支持和验证的平台，尚未提供 macOS/Linux 桌面包。

## 想参与开发：从源码运行

需要 Python 3.10–3.12 x64，推荐 3.12。Git 不是下载 ZIP 后启动的必要条件。

1. 下载仓库源码 ZIP 并解压，或在已登录 GitHub 的 Git 客户端中克隆仓库。
2. 双击 `install-desktop.cmd`。它会在源码目录建立独立 `.venv` 并联网安装依赖，不会修改已有其他项目环境。
3. 安装成功后，双击 `start-desktop.cmd`。

命令行等价操作，在源码目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-desktop.txt
.\.venv\Scripts\python.exe desktop.py
```

如果脚本提示现有 `.venv` 版本不合适，先将该文件夹改名备份，再重新安装。安装失败时保留窗口中的完整错误信息，先检查 Python 版本与网络；无需下载大型模型。

## 第一次试用

1. 上传一张自己拥有使用权限的服装照片，或使用软件内置示例，点击开始创作。
2. 添加“精致修改”节点，进入后绘制血迹、磨损、刀痕、焦痕等；按住 **M** 查看局部放大。
3. 按 **Esc** 回总览。节点可以拖回底部方案架，也可以重新拖到主线连接处插入，原输出保留。
4. 保存方案，退出后重新打开，检查自己的工作记录。

以上步骤不需要付费模型。模型生成、角色识别、联网查询是另外的可选功能。

## AI 接口由每位组员独立设置

仓库和安装包**没有作者的 API 密钥、账号登录态或个人额度**。每位组员在自己的软件中配置拥有权限的模型服务。

| 任务 | 需要的服务 | 使用方式 |
| --- | --- | --- |
| 对话与建议 | 支持聊天的在线 API 或本机聊天服务 | 在 AI 助手中设置；聊天可用不等于可以识图或生图 |
| AI 识别与检索 | 支持图片输入的视觉助手 | 插入节点，检查角色候选，确认后查询场景，最后采用；远程识图首次需同意发送缩略图 |
| 图像精修或生成 | 支持图像编辑的接口 | 在图像生成节点配置并明确执行；返回候选后再采用 |
| 本地模型 | 已启动且符合接口的本机推理服务 | 按 [模型接入说明](../LOCAL_MODELS.md) 配置服务地址 |

接口费用按各自服务商规则产生。支持“OpenAI 兼容聊天”的地址可能没有图像编辑功能。只填写模型名字，或仅成功列出模型，不能证明该服务能够生图。API 密钥只保存在当前后台进程内，关闭并重启软件后需要重新输入；不要把密钥写进仓库、Issue 或截图。

角色识别与场景选择流程已做模拟接口测试，当前发布不包含对每家付费视觉模型准确率的实测承诺。联网结果不足时会显示缺失或已缓存的来源，不会凭空确认剧情。

## 模型与可选扩展

基础桌面功能不包含模型权重，也不自动下载模型。下面功能需另行配置，缺少扩展不影响基础笔刷和工作流：

- 褶皱贴合、主体前景分析：`requirements-surface.txt` 与对应下载工具，详见 README 的表面分析部分。
- DINOv2 对应点建议：`requirements-correspondence.txt` 与下载工具；结果仍需人工核对。
- 靠近触发放大镜：可选 OpenCV 环境与摄像头权限，详见 [PROXIMITY.md](PROXIMITY.md)。默认关闭，不是手势识别或视线追踪。

各组员在本机配置运行环境路径。代码中保留的作者旧环境兼容探测不是必备安装目录，不需要创建同名盘符或文件夹。第三方权重的许可证与硬件要求应单独核对。

## 保存、更新与协作

- 桌面版和源码桌面启动默认将照片、方案、日志、窗口状态保存在程序旁的 `workspace`；浏览器开发入口默认用 `data`。
- 更新前先退出软件、备份 `workspace`。新版本使用原工作区，或把备份复制到新程序旁；不要用空目录覆盖原数据。
- 源码启动也可明确指定：`.\.venv\Scripts\python.exe desktop.py --data-dir D:\RelicWorkspace`。
- GitHub 用于协作代码；不会自动同步每个人的照片和草稿。共享作品时使用软件导出功能，并确认素材可以交给组员。
- 提交问题时附 Windows 版本、软件版本、操作步骤与脱敏截图。启动日志在 `workspace/runtime/desktop-server.log`，分享前检查其中是否有不想公开的路径或请求信息。
- 默认端口为 `127.0.0.1:17870`。若提示占用，先关闭自己之前打开的软件窗口，避免重复启动；不需要开放公网端口。

## 这一版的范围

可以做服装图像上的创作预览与节点流程试用。平铺映射需要真实平铺照片和对应点确认；制作模板需要用户确认尺寸；材料建议仍需实物小样验证。完整三维战斗、任意服装自动展开、可靠材质识别、物理血液模拟和自动制造精度均不属于本版已经完成的能力。
