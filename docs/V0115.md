# v0.11.5 模板制作

继续使用原来的“打开遗迹重构”入口。此版本完善制作收尾流程，沿用现有界面风格。

## 正确连接

真实服装输入 → 精致修改 → 效果映射 → 模板制作

在效果映射中上传真实平铺衣片，核对对应点并生成映射，再保存节点。模板制作直接读取这份结果，不需要重新手画每个血斑窗口。也可以在映射与模板之间保留制作条件或制作指导等不改变图片的节点。

“服装展平”中的 AI 候选属于形态参考，不是实测衣片。只有穿着图、只有 AI 合成效果、未保存的映射、过期结果或其他分支的映射不能直接成为加工模板。映射后再次生图或改动笔触，需要重新映射当前版本。

## 内容层级

- 制作包：本次方案的完整交付，可下载保存
- 衣片：当前映射的部件及正反面，使用统一坐标和实测尺寸
- 效果：由已记录的笔刷类型与子类型分组
- 工序：实际制作顺序、工具、动作、检查点
- 辅助文件：适合该工序的镂空模板、保护范围或描线定位图

效果分类用于查找；实际施工按全局工序顺序执行，不能把同一效果下的全部步骤做完再跳到另一效果。

## 使用步骤

1. 双击“模板制作”，查看上游平铺与映射检查
2. 选择部件正反面、已知的大致材料；未知材料可以保留未知
3. 测量整张目标平铺画幅对应的实际宽高，填写毫米值并确认
4. 生成制作包，查看“衣片—效果—工序”和统一的制作顺序
5. 下载定位图、各步模板和说明书，先打印校验尺寸并做同材质小样

照片中的衣服宽度不一定等于画幅宽度。只有相机正对、衣片平整且尺度校准可靠时，画幅毫米尺寸才有意义。不能把整张照片拉伸到想要的衣服尺寸。

## 自动模板与手工步骤

大轮廓可以成为镂空模板；细碎飞溅以允许操作的保护范围配合真实飞溅；浸染保留定位和操作建议；真实割痕、磨毛与焦痕模拟分别给出工序说明。不是所有笔刷都会产生可切割文件。

源图的光影和褶皱不用于反推血迹。独立笔触通过原映射对应关系变换到平铺坐标，未知区域不会被自动编造成已确认痕迹。过小细节的简化和支撑处理须在预览中检查。

## 实现边界

制作包来自已记录的笔刷与本地工艺规则，本步骤不调用付费模型，不需要配置 API。操作说明不是材料物理模拟，不保证不同布料使用相同动作后呈现同样效果；先比较干燥后的小样。

每个映射对应一个已确认衣片。披风、领巾、袖子以及正反面分别映射、分别输出，不从一张正面图推断背面。现有旧映射只有在原笔触与保存的映射效果能够核验一致时才继续使用，否则提示重新映射。

模板不是缝纫纸样。真实切口、材料耐受性及支撑桥是否适合具体加工工具，需要用户在样片上确认。

## 文件与版本

源笔触快照跟随映射保存。新制作包放在工作区的 `node-studio/exports/` 下，每次生成独立目录，不覆盖上次模板。更新程序不会修改个人照片、作品和模型。
