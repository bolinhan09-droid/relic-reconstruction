# v0.10 协作创作台

本版沿用标签、分支、合拢和节点历史，把助手执行、部件处理、融合与实验交互接到实际工作流。

## 从哪里开始

1. 打开桌面程序，继续已有创作或上传服装。
2. 选中精致修改等目标节点，添加下方的“协作执行”。连接只建立关系，双击进入。
3. 先按 [本地模型安装说明](../LOCAL_MODELS.md) 安装可选千问模型，或配置兼容的视觉服务。然后在助手连接中启动并等待就绪，输入具体目标，可框选位置。GitHub 下载包没有预装大型模型。
4. 点击执行，查看工具步骤及前后对比；采用候选后可“恢复采用前”。助手可以准备并接入其他工作节点。

本地助手为 Qwen3.5-4B 量化视觉模型。它能读取图片、组织思路、选择工具，不能替代图像生成模型。也可配置实际支持图片输入与工具调用的兼容服务。仅文本的 DeepSeek 等接口可辅助文字讨论，不能因此完成服装看图或视觉审阅。

## 已实现的协作

| 节点 | 本版实际行为 |
| --- | --- |
| 想法整理 | 结合服装、宿主、角色场景，整理目标和未知条件 |
| 修改建议 | 看当前图片，提供具体位置与方案建议 |
| 整体审阅 | 对照前后图片，解释变化、保留要求与待检查项 |
| 协作执行 | 调整已有笔触、新增痕迹、保护选区、调用本机分割或展平、准备新节点 |

模型只能使用应用登记的工具，不执行任意代码。不在连接时调用接口；跨节点修改先进入候选。采用与恢复不再次请求模型。上游发生变化后，旧候选不能覆盖新作品。

## 分割 → 展平 → 映射

**服装分割：** 点击衣服内部作为保留点，点击背景/其他衣物作为排除点，也可以框选。采用前预览透明部件。可重复提取袖子、披风、内搭，保存在部件库；切换部件后再连接精修。手动轮廓用于不理想的边缘。完整人物去背景是另一个按钮，会保留人物而非只截衣服。

**服装展平：** 四点校正依次标左上、右上、右下、左下，把可见衣片拉正；不恢复被褶皱遮挡的真实布料。AI 平铺会生成未知部分，输出是设计参考，复杂披风可能失真。它不是裁片、真实尺寸或已验证的血迹对应图。

**效果映射：** 上传真实平铺照片，确认穿着图与平铺图的对应位置，再计算痕迹转移。没有目标图与定位点时不产生伪造映射。尺寸、衣片前后和遮挡区域仍需人工检查。

分割和展平任务独立排队，先冻结源图。结果采用时同时校验图像及上游方案，防止旧候选覆盖新的笔触。透明裁片更换坐标后，旧坐标笔触不会重复叠加。

## 融合创作

交互借鉴多方案捏脸式探索：两版使用比例滑杆，三版使用三角控制器；靠近哪个顶点，就更偏向那一版。展开“分别保留喜欢的特征”，可指定血迹、割痕、磨损、焦痕分别来自哪个候选。

同一底图、可编辑笔触且满足相同表面条件的候选，可以本机实时预览并采用。共同祖先的相同笔触只画一次，避免重复叠加变色。不同照片、已生成的整图、复杂表面重投影等情况准备图像融合任务，交给图像节点明确生成。此处借鉴的是交互方式，不声称复制游戏的内部算法。

## 手势与三维实验

**手势：** 在工作台点击开启摄像头。捏合拇指与食指起笔，松开收笔，选择刀痕/磨损/血迹；仍保留鼠标和触控。保存归一化轨迹、动作强度和事件。摄像头只在本机处理，停止、离开和窗口隐藏会释放。已验证真实浏览器推理链路；真人手势稳定性仍需实际使用反馈。

**三维战斗：** 先旋转观察代理衣服，再切换挥刀或两点划切。只有射线扫过实际可见衣物表面才记录命中，空挥不留下痕迹。每次记录部件、空间位置、法向、方向、UV、时间和创作强度。支持正背侧视角、撤销、清空、保存重载，以及命中 JSON/UV 图导出。

这是三维代理服装上的命中实验，尚不是布料动力学或真实破坏仿真。未建立照片配准时，UV 痕迹不会被虚假投射到用户照片；后续需服装网格、UV 与实物校准。

## 模型与运行

开发电脑已安装并测试千问视觉助手、SAM2.1、主体去背景和相对深度模型；新电脑需按需另行安装。公开源码与 Windows 包不含大型权重、个人照片和开发工作区；手部小模型和浏览器运行资产随包提供。

Qwen-Image-2.1 使用独立研究许可，可按说明下载并在图像服务中启动。MGT AI 平铺依赖单独的 SSPL 研究环境，公开包未附完整研究适配器；它保留接入入口，但并非下载主软件即可使用。四点校正和真实平铺图映射可直接使用。

8GB 显卡建议交替运行视觉助手和生图。图像节点有停止助手释放显存的按钮，软件只停止自己启动的模型。Qwen 图像的小图实测不保证任意大分辨率速度或质量。官方模型链接、安装命令、运行路径配置和许可见 [LOCAL_MODELS.md](../LOCAL_MODELS.md)。

## 验证范围

- 助手：真实本机千问看图、工具调用、前后审阅；候选采用/恢复及保护像素测试。
- 服装：真实 SAM、MGT、主体与深度推理；透明输出、来源过期与防重复绘制检查。
- 融合：像素级比例变化、共同笔触不变、特征来源、保存重放。
- 三维：最近表面命中、空挥、正背分离、UV 重载与浏览器实际交互。
- 手势：本地 WASM/模型推理、权限由点击触发、释放摄像头、零外部请求。
- 整合：助手→候选→采用/恢复、分割→展平→映射入口、1024/1280 画布与分支回归。

测试没有付费云调用。图像参考、材质判断、展平补全和视觉审阅都仍需用户检查；平台不将推断当作精确材料参数或实物结果。
