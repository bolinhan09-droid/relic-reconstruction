# v0.11.4 新手练习与工作台

继续使用原来的“打开遗迹重构”入口。版本号显示 v0.11.4，原有照片、方案、模型与设置仍保存在原工作区。

## 第一次使用

1. 首页点击“跟着示例做一遍”，软件新建独立的“新手练习”项目
2. 双击精致修改标签，或者点教学中的“打开精修”
3. 在示例衣服上按住、拖动并松开，生成一次血迹飞溅；可更换笔刷，也可撤销
4. 点击工作区右上角“保存”，保存当前节点的实际输出
5. 按 Esc 返回总览，打开“制作指导”，查看上一步传来的效果

练习不需要配置 API，也不会自动调用模型。完成教学后，可以上传自己的服装开始创作。

## 退出和继续

- 教学面板可收起，也可随时“结束教学”；创作工具仍然可用
- 首页会显示“继续新手练习”。已保存的练习保留在“我的创作”，可以继续或删除
- 工作区右上角“帮助”可以重新打开教学；先保存当前作品，再切换到独立练习
- 完成后重做会创建新的练习项目。已删除练习无法恢复时，也会创建新示例
- 教学进度依据真实绘制、保存和节点进入状态推进，不替用户点击生成

## 固定工作台

保留当前配色、字体、磨损标签与纹理。本轮调整空间和操作方式：

- 整个应用不再作为长页面上下滚动
- 首页上传区与作品记录分区，作品较多时只滚动记录区域
- 创作总览保留可平移、缩放的节点画布
- 节点工作区中，画布与参数面板分别占据固定空间；长参数在面板内滚动
- 双击节点直接进入，Esc 返回，Ctrl+S 保存；连接节点不自动弹页、不调用 AI
- 小窗口下保持内容区域可滚动，避免把操作截到窗口外

## 更新与数据

Windows 包使用已有更新工具，校验 SHA256、文件清单和程序版本后替换“当前版本”，保留“上一版本”用于回退。更新前保存并关闭正在运行的窗口。更新过程不覆盖独立工作区、照片或模型。
