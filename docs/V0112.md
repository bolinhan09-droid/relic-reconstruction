# v0.11.2 保存与工作区修复

绘制后的节点输出会同时引用独立笔触、项目快照和历史。原先按缩进 JSON 的 3 MB 限制会让正常创作无法保存，且错误信息将内部实现问题交给了用户。本版自动紧凑编码，大结构按内容去重存放在工作流目录；读取和历史下载恢复完整可编辑内容。保留旧记录兼容、冲突检查和原子写入，设有 64 MB 展开记录安全上限。

节点内部只使用一条顶部工具栏：返回总览、节点名称、画布工具、状态和保存。精修时隐藏总览的全局标题栏，移除重复的返回/保存行和画布工具行；放大镜与靠近感知移入同一工具栏，缩放、原图、背景与拖动画面放入“视图”。衣服表面分析移至侧栏，画布可使用剩余窗口高度。

保存后继续编辑；返回总览或在画布按 Esc 时，先保存已修改的笔触。保存失败会留在当前画布，重试仍保留全部笔触。未编辑的返回不会额外制造输出版本。画布内 Ctrl/Cmd+S 保存当前编辑状态。

首页两个开始选项横向排列。只在真正等待创作模块时显示简洁加载界面，快启动直接进入；本机历史独立读取。移除装饰性启动闪屏，保留上传图片缩入节点的空间过渡。

验证：大记录及旧格式读取、历史恢复、共享素材删除、节点保存、真实画布绘制/重开、写入失败后重试、工作区快速切换及首页加载已分别检查；测试没有调用付费模型或打开用户摄像头。
